# keras-monkeys

# 🐒 Monkey Species Classifier

This project uses **Keras and MobileNetV2** to classify **10 monkey species** from the Kaggle dataset.  
It was built and trained entirely in **Google Colab** using **transfer learning**.  Just click on the Colab link to run the cells. 
The notebook downloads the dataset, trains the model, fine-tunes it, and shows accuracy/loss plots plus 25 test predictions.  
All results (plots, model, and tuning logs) are automatically saved to Google Drive.
