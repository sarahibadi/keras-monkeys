# keras-monkeys

# 🐒 Monkey Species Classifier

This project uses **Keras and MobileNetV2** to classify **10 monkey species** from the Kaggle dataset. I used a Kaggle API key to access the data.   
It was built and trained entirely in **Google Colab** using **transfer learning**.  Just click on the Colab link to run the cells. 
The notebook downloads the dataset, trains the model, fine tunes it, and shows accuracy/loss plots + 25 test predictions.  
All results are automatically saved to Google Drive.
